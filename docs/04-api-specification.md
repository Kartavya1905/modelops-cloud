# 04 — API Specification

> Status: **Design (Phase 0)**. The executable contract is the OpenAPI document generated by `@nestjs/swagger` and committed at `packages/api-contract/openapi.json` (from M2). This page defines conventions and the endpoint inventory, which the generated spec must match.

## 1. Two APIs, two audiences

| API | Base URL (local) | Auth | Consumer |
|---|---|---|---|
| **Management API** (control plane) | `http://localhost:3300/api/v1` (proxied by Next.js) → `api:4000` | Session cookie + CSRF header | Web app, scripts |
| **Inference API** (data plane) | `http://localhost:18080/v1` | `Authorization: Bearer <api-key>` | Client applications, load tests |

## 2. Conventions

### Versioning
- URI-versioned: `/api/v1`, `/v1`. Additive changes (new fields, new endpoints) are non-breaking. A breaking change means `/v2`.
- Deprecated endpoints return `Deprecation` and `Sunset` headers.

### Request and response format
- JSON, `camelCase` fields, ISO-8601 UTC timestamps, UUID ids.
- Every response carries `X-Request-Id`, either echoed from the request or generated. The same id appears in logs and traces.

### Errors: RFC 9457 Problem Details

```json
{
  "type": "https://modelops.local/problems/invalid-state-transition",
  "title": "Invalid state transition",
  "status": 409,
  "detail": "Revision 3 is FAILED and cannot be promoted.",
  "instance": "/api/v1/orgs/7f.../endpoints/2a.../promote",
  "code": "INVALID_STATE_TRANSITION",
  "requestId": "01J...",
  "errors": [{ "field": "revisionId", "message": "must be READY" }]
}
```

| Status | `code` examples |
|---|---|
| 400 | `VALIDATION_FAILED`, `SIGNATURE_MISMATCH` |
| 401 | `UNAUTHENTICATED`, `INVALID_API_KEY` |
| 403 | `FORBIDDEN_ROLE`, `SELF_APPROVAL_NOT_ALLOWED`, `CSRF_TOKEN_INVALID` |
| 404 | `NOT_FOUND` (also used for cross-tenant access) |
| 409 | `INVALID_STATE_TRANSITION`, `DEPLOYMENT_IN_PROGRESS`, `IDEMPOTENCY_KEY_REUSED` |
| 413 | `ARTIFACT_TOO_LARGE` |
| 415 | `UNSUPPORTED_ARTIFACT_TYPE` |
| 422 | `MODEL_NOT_VALIDATED`, `GATE_NOT_PASSED` |
| 429 | `RATE_LIMITED` (+ `Retry-After`) |
| 503 | `DEPENDENCY_UNAVAILABLE`, `NO_READY_REVISION` |

### Pagination
Cursor-based: `?limit=25&cursor=<opaque>` returns `{ "data": [...], "nextCursor": "..." | null }`. Maximum `limit` is 100.

### Idempotency
- Required on `POST` endpoints that start asynchronous work: deploy, rollback, promote, canary, evaluation, drift run.
- Header: `Idempotency-Key: <uuid>`, scoped per organization and stored for 24 h.
- Same key + same body hash → the **original response is replayed** (same status, same body).
- Same key + different body → `409 IDEMPOTENCY_KEY_REUSED`.
- A request still in progress under the same key → `409 DEPLOYMENT_IN_PROGRESS`, with `Retry-After`.

### Concurrency control
Mutable aggregates (endpoint traffic settings) expose an `ETag`. Mutations require `If-Match`, and a stale `ETag` returns `412 Precondition Failed`. This stops two admins from overwriting each other's canary weight.

### Rate limits (defaults)
| Scope | Limit |
|---|---|
| `POST /auth/login` per IP + email | 5 / minute |
| Management API per session | 300 / minute |
| Inference per API key | Endpoint's `rateLimitRps` (default 50 rps, burst 100) |

## 3. Management API inventory (`/api/v1`)

Role abbreviations: **O** Owner, **A** Admin, **E** ML Engineer, **V** Viewer. "Any" means any member of the org.

### Auth and session
| Method | Path | Role | Description |
|---|---|---|---|
| POST | `/auth/register` | public | Create user (+ personal org) |
| POST | `/auth/login` | public | Start session, set cookie, return CSRF token |
| POST | `/auth/logout` | session | Revoke session |
| GET | `/auth/me` | session | Current user, memberships, CSRF token |

### Organizations and members
| Method | Path | Role | Description |
|---|---|---|---|
| GET | `/orgs` | session | Orgs I belong to |
| POST | `/orgs` | session | Create org (creator becomes Owner) |
| GET | `/orgs/{orgId}` | Any | Org detail |
| GET | `/orgs/{orgId}/members` | Any | List members |
| PATCH | `/orgs/{orgId}/members/{userId}` | O, A | Change role (only an Owner can grant Owner) |
| DELETE | `/orgs/{orgId}/members/{userId}` | O, A | Remove member (cannot remove the last Owner) |
| POST | `/orgs/{orgId}/invitations` | O, A | Create invite, return a one-time link |
| POST | `/invitations/{token}/accept` | session | Join org |

### Projects, datasets, experiments
| Method | Path | Role | Description |
|---|---|---|---|
| GET / POST | `/orgs/{orgId}/projects` | Any / O, A, E | List / create |
| GET / PATCH / DELETE | `/orgs/{orgId}/projects/{projectId}` | Any / O, A, E / O, A | Detail / update / archive |
| GET / POST | `/orgs/{orgId}/projects/{projectId}/datasets` | Any / O, A, E | Dataset versions |
| GET | `/orgs/{orgId}/projects/{projectId}/runs` | Any | MLflow runs (filter, sort, paginate) |
| GET | `/orgs/{orgId}/runs/compare?ids=a,b,c` | Any | Aligned params and metrics for 2–5 runs |

### Registry
| Method | Path | Role | Description |
|---|---|---|---|
| GET / POST | `/orgs/{orgId}/projects/{projectId}/models` | Any / O, A, E | Registered models |
| GET | `/orgs/{orgId}/models/{modelId}` | Any | Model + versions summary |
| POST | `/orgs/{orgId}/models/{modelId}/versions/import` | O, A, E | Import from MLflow run `{ runId, artifactPath, datasetVersionId }` |
| POST | `/orgs/{orgId}/models/{modelId}/versions/upload-url` | O, A, E | Get presigned PUT URLs for a bundle upload |
| POST | `/orgs/{orgId}/models/{modelId}/versions` | O, A, E | Finalise uploaded bundle → `PENDING_VALIDATION` |
| GET | `/orgs/{orgId}/model-versions/{versionId}` | Any | Detail, signature, lineage |
| GET | `/orgs/{orgId}/model-versions/{versionId}/validation` | Any | Latest validation report |
| POST | `/orgs/{orgId}/model-versions/{versionId}/validation/rerun` | O, A, E | Re-validate (e.g. after validator outage) |
| POST | `/orgs/{orgId}/model-versions/{versionId}/evaluations` | O, A, E | Evaluate against baseline `{ baselineVersionId, datasetVersionId }` (async) |
| GET | `/orgs/{orgId}/model-versions/{versionId}/evaluations` | Any | Evaluation reports |
| PUT | `/orgs/{orgId}/model-versions/{versionId}/aliases/{alias}` | O, A | Set `champion` / `challenger` (`champion` requires a passed gate) |

### Endpoints, deployments, releases
| Method | Path | Role | Description |
|---|---|---|---|
| GET / POST | `/orgs/{orgId}/projects/{projectId}/endpoints` | Any / O, A, E | List / create endpoint |
| GET | `/orgs/{orgId}/endpoints/{endpointId}` | Any | Detail: traffic split, current revisions, ETag |
| PATCH | `/orgs/{orgId}/endpoints/{endpointId}` | O, A | Settings (rate limit, input capture) + `If-Match` |
| POST | `/orgs/{orgId}/endpoints/{endpointId}/revisions` | O, A, E | **Deploy** `{ modelVersionId, resources? }` + `Idempotency-Key` → `202` with revision |
| GET | `/orgs/{orgId}/endpoints/{endpointId}/revisions` | Any | Revision history |
| GET | `/orgs/{orgId}/revisions/{revisionId}` | Any | Revision detail + current state |
| GET | `/orgs/{orgId}/revisions/{revisionId}/events` | Any | Timeline events |
| POST | `/orgs/{orgId}/revisions/{revisionId}/cancel` | O, A, E (own) | Cancel before `READY` |
| PUT | `/orgs/{orgId}/endpoints/{endpointId}/canary` | O, A (prod), E (staging) | `{ revisionId, weight }` + `If-Match` |
| POST | `/orgs/{orgId}/endpoints/{endpointId}/promote` | O, A (prod), E (staging) | Canary → stable |
| POST | `/orgs/{orgId}/endpoints/{endpointId}/rollback` | O, A (prod), E (staging) | `{ targetRevisionId? }`, defaults to the last healthy one |
| POST | `/orgs/{orgId}/endpoints/{endpointId}/playground/predict` | Any | Playground call (server-side, uses an internal key, rate-limited) |

### Approvals
| Method | Path | Role | Description |
|---|---|---|---|
| GET | `/orgs/{orgId}/approvals?status=PENDING` | Any | Approval queue |
| POST | `/orgs/{orgId}/approvals/{approvalId}/approve` | O, A (not the requester) | Approve → revision proceeds to `QUEUED` |
| POST | `/orgs/{orgId}/approvals/{approvalId}/reject` | O, A | Reject with reason → revision `CANCELLED` |

### Monitoring
| Method | Path | Role | Description |
|---|---|---|---|
| GET | `/orgs/{orgId}/endpoints/{endpointId}/metrics?range=1h&step=30s` | Any | Pre-defined series (rps, p50/p95/p99, errors, split, cpu, mem). **No arbitrary PromQL** |
| GET | `/orgs/{orgId}/endpoints/{endpointId}/performance?window=1h` | Any | Accuracy, F1, ROC-AUC from feedback |
| GET / POST | `/orgs/{orgId}/endpoints/{endpointId}/drift-reports` | Any / O, A, E | List / run now |
| GET | `/orgs/{orgId}/drift-reports/{reportId}` | Any | Per-feature scores (+ presigned link to the HTML report) |
| GET | `/orgs/{orgId}/platform/metrics` | O, A | Queue depth, job failures, stage durations |

### API keys and audit
| Method | Path | Role | Description |
|---|---|---|---|
| GET / POST | `/orgs/{orgId}/projects/{projectId}/api-keys` | O, A | List (prefix only) / create (secret returned **once**) |
| DELETE | `/orgs/{orgId}/api-keys/{keyId}` | O, A | Revoke |
| GET | `/orgs/{orgId}/audit-events?action=&actor=&from=&to=&cursor=` | O, A | Audit log |

### Health (unauthenticated, internal)
| Method | Path | Description |
|---|---|---|
| GET | `/health/live` | Process is up |
| GET | `/health/ready` | Postgres + Redis reachable |
| GET | `/metrics` | Prometheus scrape (internal network only) |

## 4. Inference API (`gateway:18080/v1` (container port 8080))

### Predict

```http
POST /v1/endpoints/churn-prod/predict
Authorization: Bearer mo_7KQ2X9AB_<secret>
Content-Type: application/json
X-Routing-Key: customer-1234          (optional; sticky canary assignment)

{
  "inputs": [
    { "tenure_months": 14, "monthly_charges": 72.5, "support_tickets": 3,
      "contract_type": 1, "late_payments": 0, "usage_hours": 41.2 }
  ]
}
```

```json
{
  "predictionIds": ["0193b0c4-..."],
  "model": { "name": "churn-classifier", "version": 4, "framework": "PYTORCH_ONNX" },
  "revisionId": "8e1c...",
  "outputs": [{ "label": 1, "probabilities": { "0": 0.21, "1": 0.79 } }],
  "latencyMs": 6.4
}
```

- Response headers: `X-Model-Version`, `X-Revision-Id`, `X-Request-Id`.
- Inputs are validated against the model signature at the gateway: unknown or missing fields, wrong types, or batch size over 64 → `400`.
- Errors use the same Problem Details format.
- Inputs are **never** logged. They are captured for drift only when the endpoint has `captureInputs=true`.

### Feedback (ground truth for measured performance)

```http
POST /v1/endpoints/churn-prod/feedback
Authorization: Bearer mo_...
{ "items": [{ "predictionId": "0193b0c4-...", "label": 1 }] }
```
→ `202 Accepted`. Labels for unknown or expired prediction ids are counted and ignored.

### Model server (internal only, not exposed outside the `inference` network)
| Method | Path | Description |
|---|---|---|
| GET | `/healthz` | Process up |
| GET | `/readyz` | Model loaded and checksum verified |
| GET | `/metadata` | Signature, model version, checksum, ORT version |
| POST | `/v1/predict` | Tensor-level prediction (gateway has already validated) |
| GET | `/metrics` | Prometheus |

## 5. Contract workflow

```text
NestJS DTOs (class-validator + @nestjs/swagger)
   └─► pnpm --filter api openapi:emit   → packages/api-contract/openapi.json (committed)
         └─► pnpm --filter api-contract generate → src/schema.d.ts (openapi-typescript)
               └─► apps/web imports createClient<paths>() from openapi-fetch
CI: regenerate both and run `git diff --exit-code` → fails on drift
```
